# 누리호(KSLV-II) 프로젝트

우송4반 바이오헬스아카데미 수업 실습 (2026-10-13) — AI와 함께 하는 프로그래밍

## 진행 과정
1. **NotebookLM** — 누리호 기사·자료 수집 → 소스 채택 → 슬라이드 구성 생성
2. **gamma.app** — 발표 PPT 제작
3. **genspark.ai** — 샌드박스 웹 앱 제작
4. **GitHub** — REPO 저장 + GitHub Pages 정적 웹사이트 게시
